On this computer

Here the app is the Buddy's editor: open Make it yours to change its pages, look and settings with a live preview, and apply them over the USB cable.

The background helper (lock state, meetings, Claude Code, "Say something") is set up on Linux.

Before you start

Plug the Buddy into this computer with its USB cable. The firmware must be on it already: that is done from the installer page.

Setup makes two secret keys on this computer and hands them to the Buddy over the cable. They are never shown and never leave this computer any other way.
